# 펭귄 수학교실

## 시계 읽기와 화면 선택
- 교사 화면의 학습 활동에서 덧셈 또는 시계 읽기를 고릅니다.
- 시계는 정각·30분·5분 간격과 시·분을 고른 뒤 새 문제 보내기를 누릅니다.
- 지원 방식 선택에서 학생 선택 모드 또는 교사 선택 모드를 고릅니다. 정책 변경은 문제와 제출 기록을 유지하면서 즉시 적용됩니다.
- 교사 선택 모드에서는 학생의 도움 화면 탭이 숨겨지고 공통 지원이 적용됩니다. 학생별 지원 칸에서 개별 학생만 다른 방식으로 지정할 수도 있습니다. 공통 지원 사용을 고르면 공통값을 따릅니다.
- 학생 선택 모드에서는 학생이 직접 도움 화면을 고릅니다. 교사 지정은 화면만 숨기는 것이 아니라 서버에서도 제출 모드를 검증합니다.
- 시계의 짧은 바늘은 분에 따라 이동합니다. 12시는 0시가 아니라 12시로 처리합니다.
- 업데이트 후 교사와 학생 페이지를 새로고침해야 새 기능이 적용됩니다.


초등학생용 파스텔 펭귄 덧셈·시계 읽기 활동과 교사용 실시간 답안 확인 예제입니다. GitHub Pages에 앱 코드만 배포하고, 답안은 Firebase Spark Realtime Database에 저장합니다.

## 사용법
- 교사: 배포 주소에 `?role=teacher`를 붙여 Google 로그인 후 새 교실을 엽니다.
- 학생: 교사가 준 학생 링크로 접속해 교실 코드와 좌석번호(1~99)로 입장합니다.
- 유효한 숫자 답은 정답·오답 모두 전송되고, 교사는 최신 답·정답 여부·시도 횟수·제출 시각을 확인합니다.
- 교사가 새 문제를 보내면 같은 교실 학생 화면도 바뀝니다.
- `?demo=1`은 답안을 서버에 보내지 않는 오프라인 연습 모드입니다.

## 파일
- index.html: 생성한 펭귄 이미지를 내장한 학습 활동과 교실 화면
- classroom.js / classroom.css: Firebase 연결과 실시간 교사·학생 화면
- firebase-config.js: Firebase의 공개 웹 앱 식별 설정. 관리자 키나 사용자 토큰이 아닙니다.
- database.rules.json: Firebase 콘솔에 별도 게시한 기본 거부 접근 규칙

## 보안·개인정보
학생 실명·진단·장애정보를 수집하지 않습니다. 교사는 자신의 교실만 전체 조회하고, 학생은 자신의 답만 다룹니다. 다른 학생의 좌석 UID 조회·답안 읽기/쓰기·교사 문제 변경·정답 플래그 위조·중복 좌석 예약을 서버 규칙으로 차단합니다. 학생 답안·교사 로그인 토큰·서비스 계정 비밀키는 이 저장소에 포함하지 않았습니다.

익명 로그인과 참여 코드를 쓰는 시연용 구조입니다. 참여 코드를 공개 게시하지 마세요. 학생 계정은 탭 세션에 유지되므로 탭을 닫으면 기존 자리 복구가 어려울 수 있습니다. 자리 비우기·과거 문제 조회·CSV 내보내기·자동 삭제 화면은 아직 없고, 교사가 Firebase 콘솔에서 기록을 관리해야 합니다. 실제 학교 운영 전 App Check/남용 방지, 개인정보 보관·삭제 정책을 검토하세요.

## 무료 범위
Firebase Spark를 사용하며 Blaze나 Cloud Functions를 사용하지 않습니다. Realtime Database 무료 한도(동시 연결100, 저장1GB, 월 다운로드10GB) 안에서 사용해야 합니다.

## 설정
이 저장소 루트를 GitHub Pages의 main 브랜치 배포 폴더로 선택합니다. 새 호스팅 주소에서는 Firebase Authentication 승인된 도메인을 설정해야 합니다. Firebase 설정은 각자 소유 프로젝트로 바꿔 사용할 수 있습니다. 접근 규칙은 해당 프로젝트에 직접 게시해야 합니다.
